# 张跃 / Yue Zhang 学术主页 v7

本版包含中英文首页、完整论文页、照片、原有简历和本地英文字体。

## 本地查看

1. 完整解压压缩包。
2. 双击根目录的 index.html 查看英文首页。
3. 点击右上角“中文”查看中文版；点击“发表论文 / Publications”查看完整论文。
4. 也可直接打开 zh/index.html 查看中文首页。

请先解压，再打开网页。页面样式和字体均在本地，无需安装软件。

## 更新 GitHub Pages

将压缩包中的内容上传到 Leon1995-ai.github.io 仓库根目录，替换同名文件。需要上传：
- index.html
- publications.html
- academic-v7.css
- academic-v7.js
- zh 文件夹（内有两个 HTML 文件）
- assets 文件夹（照片、简历、图标和 fonts 文件夹）

不要把外层文件夹作为一个新目录上传。仓库根目录应直接包含 index.html。
已有的 .nojekyll 可以保留；本次不需要重新上传它。
旧版 academic-v6.css / academic-v6.js 不再被新网页引用，可以暂时保留。

GitHub Pages 继续使用原有 main 分支与根目录配置。待发布任务完成后，在浏览器按 Ctrl+F5 刷新。

本次没有改动你的线上仓库。先查看本地版本，再上传。
