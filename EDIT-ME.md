# Quick edits

Most content is in `index.html`.

## Main profile links
Search for `link-row` in `index.html` to update Email, ORCID, IEEE Xplore, GitHub, or CV.

## Publications
Search for `Journal Articles`, `Conference Papers`, and `Manuscripts Under Review`.
Each paper is one `<li class="publication" ...>` block.

## Projects
Search for `Research Projects` and edit the two `project-card` blocks.

## Style
Typography, spacing, colors, and responsive layout are in `style.css`.
The site intentionally uses system fonts (Segoe UI / Helvetica Neue / PingFang SC / Microsoft YaHei) so it loads cleanly without external font services.
